# Academic Writing lessons

Each lesson lives in its own directory under `resources/academic-writing/` and has an `index.html`. To add a lesson:

1. Create a new lesson directory and page, using `extreme-heat-old-age/` as the layout reference.
2. Add its title, date, level, topics, search keywords, description, and relative page path to `catalog.js`.
3. Keep the source citation and permissions clear. When a source article cannot be republished, link to it and write a separate training passage.

The catalog page provides text search and topic filtering, so additional lessons can be added without changing the navigation structure.
